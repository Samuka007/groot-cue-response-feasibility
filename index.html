Can a frozen VLA react when the world changes?冻结骨干的 VLA 能否在世界发生变化时作出反应？

We made the question deliberately small. A stationary cube changes from blue to red. The EEF does not move. The policy only has to close the gripper. This isolates a visual condition change from the much larger problem of manipulation.我们刻意把问题缩到最小。 一个静止方块从蓝色变成红色；末端执行器不移动；策略只需闭合夹爪。这样可以把“视觉条件变化”与更复杂的操作能力分离。

The narrow claim核心的窄命题

Red enters the input. Close appears immediately.输入出现红色，闭合动作立即出现。

This is not a claim about temporal cognition, grasping, lifting, or general reflexes. It is a controlled test of whether an action head can map a visible state to a simple actuator response while remaining quiet in the matched blue control.这不是关于时间认知、抓取、抬升或一般反射能力的结论，而是一个受控测试：动作头能否把可见状态映射为简单的执行器响应，同时在匹配的蓝色对照中保持安静。

What was measured beyond the proof最小证明之外测了什么

A ladder of demands, not a history of runs.这是能力需求阶梯，不是实验流水账。

The experiments below are useful only when their extra capability requirements are made explicit. The first arm asks whether a response can be learned. The later arms ask different questions.下面的实验只有在明确额外引入了哪些能力要求时才有意义。第一层问“响应能否学会”，后续各层问的是不同问题。

LEVEL 0 · COMPLETE

State → action状态 → 动作

Static cube, fixed EEF, blue/no-cue versus red/close. Tests visual state discrimination plus action-head mapping. No temporal reasoning or physics completion.静止方块、固定 EEF、蓝色对照与红色闭合。测试视觉状态区分和动作头映射，不测试时间推理或物理任务完成。

LEVEL 1 · NEXT

Action → contact动作 → 接触

Put the cube inside the closing envelope, still keep EEF fixed. Contact is a secondary physical consequence; do not require lift or retention.把方块放进夹爪闭合范围，但仍固定 EEF。接触只作为次级物理结果，不要求抬升或保持。

LEVEL 2 · CONTROL

Action → short press动作 → 短按压

Use a button or fixed post-response motion. This adds spatial contact but avoids the hidden “did the gripper attach?” state.使用按钮或固定的响应后短动作。它增加空间接触，但避开“夹爪是否真的附着”的隐藏状态。

LEVEL 3 · STRESS TEST

Moving target移动目标

Restore follow, approach, timing, closed-loop tracking, and recovery. A failure here cannot be attributed to reaction alone.重新加入跟随、接近、时序、闭环跟踪和 recovery。此处失败不能单独归因于反应能力。

LEVEL 4 · SEPARATE TASK

Lift / hold抬升 / 保持

Requires hidden attachment-state handling and long-horizon motor control. Useful manipulation research, but not a clean reaction metric.需要处理隐藏的附着状态和长时程运动控制。它适合研究操作能力，但不是干净的反应指标。

The pitch question对 pitch 的关键追问

Does 142 ms mean GR00T is already fast enough?142 ms 是否意味着 GR00T 已经足够快？

No—not by itself. The minimal probe establishes a policy-query baseline in a static, synchronous simulator. It does not establish a low end-to-end sensor-to-actuator latency.不能这样推断。 最小实验只在静态、同步模拟器中建立了 policy-query baseline，并没有证明完整 sensor-to-actuator latency 很低。

What the number includes这个数字包含什么

The measured wall time is the observed policy request interval in the server-client setup. It is a useful baseline for this implementation, but not a complete physical control-loop measurement.测得的 wall time 是 server-client 架构中的 policy request interval。它是当前实现的有用基线，但不是完整的物理控制环测量。

Te2e = Tcapture + Tqueue + Tpreprocess + Tinfer + Ttransport + Tactuate

The current static probe largely removes the cost of target motion and contact failure. Its simulated “0 steps” means the action is selected on the first red-visible control tick, not that the physical response is instantaneous.当前静态实验基本移除了目标运动和接触失败的成本。“0 simulated steps”表示动作在第一个红色可见的 control tick 被选出，不表示物理响应瞬时完成。

Why optimization may still matter为什么优化仍可能有意义

At 20 Hz, one control tick is 50 ms. A 142 ms policy request is roughly 2.8 control periods. If the world continues evolving while inference runs, the relevant question is how much state changes before action availability.20 Hz 下一个 control tick 是 50 ms；142 ms 的 policy request 约等于 2.8 个控制周期。如果推理期间世界继续变化，关键问题是动作可用前状态改变了多少。

The optimization thesis needs a dynamic consequence.优化论点必须落到动态后果。

Optimizing a static blue→red gripper-close probe is unlikely to demonstrate meaningful task benefit: the world does not move, and the action window is effectively unlimited. An optimization module earns its place only if it reduces a measured delay component and prevents misses, stale actions, or unsafe discontinuities on a task whose outcome changes at the relevant time scale.优化静态蓝→红闭合实验很难展示有意义的任务收益：世界不动，动作窗口实际上无限。只有当优化模块降低了某个已测得的延迟分量，并在结果随时序变化的任务中减少 miss、stale action 或不安全的不连续，它才值得被引入。

A more useful research lens更有用的研究视角

From “is it fast?” to “when does latency change the answer?”从“它快不快？”转向“延迟何时会改变答案？”

The minimal study answers capability feasibility. It also tells us what the next scientific claim would have to add: a dynamic, timestamped situation in which different latencies produce different outcomes.最小实验回答了能力可行性，也说明下一个科学论点必须增加什么：一个有时间戳的动态情境，使不同延迟真正产生不同结果。

What a meaningful optimization study would hold fixed有意义的优化实验应固定什么

  • Policy checkpoint, prompt, observations, action interface, seeds, and evaluation tasks.固定 policy checkpoint、prompt、observations、action interface、随机种子和评估任务。
  • Realized delay traces replayed across all methods.让所有方法重放相同的真实 delay trace。
  • Same asynchronous execution semantics: physics continues while a new action is being inferred.保持相同的异步执行语义：推理新动作时物理仍继续运行。
  • Separate measured components: capture, queue, preprocessing, inference, transport, actuation.分别测量 capture、queue、preprocessing、inference、transport 和 actuation。

What it should measure它应测量什么

  • Success or event-miss rate versus injected/measured delay.success 或 event-miss rate 随注入/实测延迟的变化。
  • Object displacement and robot-state displacement during inference.推理期间的物体位移和机器人状态位移。
  • Action staleness, inter-chunk discontinuity, jerk, and collision/contact failures.action staleness、chunk 间不连续、jerk 以及碰撞/接触失败。
  • Latency-insensitive negative controls alongside short-window dynamic tasks.在短窗口动态任务旁加入对延迟不敏感的 negative control。

A candidate next experiment一个候选的下一步实验

Keep the cue-response logic, but make the response window finite: a visible red event enables one short press or contact opportunity while the target continues moving. Compare a synchronous baseline, naive asynchronous execution, and the proposed optimized module under the same delay trace. Start with a 50–200 ms event window and report the full curve rather than one aggregate success number.保留 cue-response 逻辑，但把响应窗口设为有限：红色事件出现后，在目标继续移动时只提供一次短按压或接触机会。在相同 delay trace 下比较同步 baseline、朴素异步执行和拟议优化模块。先从 50–200 ms 的事件窗口开始，报告完整曲线，而不是单个 aggregate success number。

The key test: does the module improve outcomes specifically when the latency scale is comparable to the task’s available response window?关键测试：只有当延迟尺度接近任务可用响应窗口时，模块是否才会改善结果？

Current position当前判断

The pitch should carry a substantial question mark, not a premature victory lap. The minimal probe is valuable because it cleanly establishes that the frozen-backbone policy can be taught a fast conditional action. It does not show that GR00T’s end-to-end latency is already low, and it does not yet justify an optimization module. The justification must come from a dynamic task where measured latency consumes a meaningful fraction of the action window or causes measurable state staleness.这个 pitch 应保留实质性的问号，而不是提前庆功。最小实验的价值在于清楚证明：冻结骨干策略可以学会快速的条件动作。但它没有证明 GR00T 的端到端延迟已经足够低，也还不能证明需要优化模块。论证必须来自动态任务：实测延迟消耗了响应窗口的显著比例，或造成了可测量的状态陈旧。
